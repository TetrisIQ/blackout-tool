Vendored for the offline map viewer (served from `/maps/vendor/`):

- `leaflet.js`, `leaflet.css` - Leaflet 1.9.4, BSD-2-Clause, https://leafletjs.com
- `maplibre-gl.js`, `maplibre-gl.css` - MapLibre GL JS 5.24.0, BSD-3-Clause, https://github.com/maplibre/maplibre-gl-js
- `leaflet-maplibre-gl.js` - @maplibre/maplibre-gl-leaflet 0.1.4, ISC, https://github.com/maplibre/maplibre-gl-leaflet

Map data is not part of this repository: it comes from the Kiwix `maps_en_<country>` ZIM files
(vector tiles, style, fonts and sprites by OpenFreeMap / OpenMapTiles, data (c) OpenStreetMap
contributors, ODbL-1.0).
